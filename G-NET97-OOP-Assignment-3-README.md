# G-NET97 OOP — Assignment 3: Advanced OOP

C# console delivery system demonstrating advanced object-oriented programming concepts.

## Concepts Covered

- **Inheritance hierarchy** — Shipment types with method overriding (`UpdateWeight` overloads)
- **Static members** — `DeliveryHelper` utility class
- **Sealed classes/methods** — `CompletedShipment`, `PriorityInternationalShipment` with `GenerateCustomsReport()`
- **Composition** — Driver-assigned `DeliveryCenter`

## How to Run

```bash
dotnet run
```

## Tech Stack

- C# / .NET
- Console Application
